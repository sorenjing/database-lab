## 笔记约定

1. 每个主题单独使用一个 Markdown 文件，以「概念 → 示例 → 易错点 → 验证 → 结论」组织。
2. SQL 实验脚本与理论笔记分开管理；能直接运行的代码保存在实验目录。
3. 对于 `EXPLAIN`、事务和锁等涉及环境差异的内容，区分**预期行为**与**实际运行结果**；未执行时标注「未验证」。
4. 仅提交脱敏、可公开的模拟数据，不提交本地密码、真实业务数据和 `.env`。
5. 每次学习只增量更新相关主题；不把聊天全文原样搬入仓库，也不将「计划学习」标成「已掌握」。

> 第 00、01 课教程和练习材料已准备，**尚无用户本机成功连接或运行 SQL 的验收结果**，不将材料已写完误标为已掌握。
